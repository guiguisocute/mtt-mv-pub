# DEATH BY GLAMOUR · 像素 MV

基于 UNDERTALE 曲目 *Death by Glamour*（148 BPM）编排的像素舞台剧。无构建步骤，打开即可播放。

**在线观看：[mtt.guiguisocute.com](https://mtt.guiguisocute.com/)**

叙事是**完美线**：整场战斗建立在玩家的一句「自夸」上 ——「* 你说自己一次也不会被碰到。」MV 就是这句大话的兑现：镁塔顿 EX 倾尽全力的每一招都被黄心在拍子上化解，两人把一场处刑变成一台同步的狂热演出，收视率从 3995 一路飙到封顶的 12000。开场是没有音乐的舞台演出，音乐从镁塔顿 EX 在烟雾中亮相的那一刻才响起，结尾是白闪断电谢幕。

## 本地播放

```sh
node tools/serve.cjs                 # http://127.0.0.1:4173
node tools/build.cjs                 # 复制网页运行需要的文件到 dist/site
node tools/serve.cjs 4173 dist/site  # 预览发布包
```

也可用浏览器直接打开 `index.html`（`file://` 即可）。页面没有 npm 运行时依赖。

- `空格` / `Z`：播放 / 暂停
- `←` `→`：快退 / 快进 2 秒（按住 Shift 为 1 小节）
- `D`：显示时间 / 小节 / 段落 / 收视率
- 点击底部进度条跳转
- URL 参数：`?t=40` 从 40 秒开始；`?lat=0.03` 调整画面与声音的延迟校准；`?cut=tiktok` 播放竖屏版

## 导出成片

需要 Node、ffmpeg，以及 Playwright Chromium：

```sh
npm install playwright
npx playwright install chromium
```

```sh
node tools/render.cjs --gpu --vcodec=h264_nvenc --workers=2
# → dist/mv_1080p60.mp4（1920×1080 60fps，已混入音效）

node tools/render.cjs --cut=tiktok --gpu --vcodec=h264_nvenc --workers=3
# → dist/mv_tiktok_1080x1920_60.mp4
```

不加 `--gpu` 时用 SwiftShader（纯 CPU）。`--frames=dist/frames` 只写 JPEG 帧和 `dist/mix.wav`，之后自己用 ffmpeg 编码。其余参数（`--fps --w --h`、`--t0 / --t1`、`--vcodec / --vopts`、`--channel=chrome`、`--headful`、`--audio-only`）见 `tools/render.cjs` 文件头；环境变量 `FFMPEG` 指定 ffmpeg 路径。

混音：`music.mp3` 从 T.pre（14 秒，序幕结束）开始，前面的序幕和后面 30 秒的谢幕只有音效；音乐压低 4 dB 给音效留余量，只在总和削波时整体下调，`--limit` 改用前视峰值限制器。

## 竖屏版（`?cut=tiktok`）

1080×1920 60fps，全片保留（序幕 → 83 小节 → 谢幕，178.6 秒），声音和 16:9 版相同，按竖屏重新取景。

- **竖屏取景**：16:9 编排的镜头在竖屏里按 `TL.pcam` 放宽（默认 k = 0.6）。第一人称体素段（40–47）按同一个 k 换算纵向视场角。
- **自动补位**：必须完整出现在画面里的东西登记在 `TL.focus` 里（菜单旁白、台词气泡、「查看」数据卡、黄心）。`H.framePortrait` 逐帧算出竖屏视野还差多少，提前拉开 / 平移，过后再收回，结果写入 `TL.pcam`。安全区：顶栏以下（HUD 在场时是 HUD 以下）、底部文案区以上（`MV.PTOP` / `MV.PSAFE`）。
- **气泡往里收**：身边的气泡收到竖屏宽度以内，尾巴仍指向说话者。
- **HUD 上屏**：收视率面板在竖屏里画在左上角顶栏下方；LIVE 标和 COMBO 在右上角。
- **屏幕层排版**：论文换成竖版稿纸；FEVER 进度条和太鼓谱面挪到 HUD 下方；老虎机下移到他身上。
- **竖屏镜头**（`src/tl_tiktok.js`）：Muse Dash 横版跑酷（48–54）推近，判定位置贴着左边缘内侧；太鼓段（64–70）拉远、下移，谱面不压头。
- 所有竖屏分支都以 `MV.PORTRAIT` 为条件，16:9 版不受影响。

## 规则

- **完美线**：永远不选「战斗」；HP 全程 20 / 20。黄心的子弹可以打他的道具，也可以打他胸口的心形核心。
- 行动菜单四个选项都用上：自夸（第 9 小节）、摆姿势（24）、翻脸（55）、查看（71）。
- 一个画面一个机位。
- 音游致敬只取五家，只借表现形式：**Beat Saber · CHUNITHM · Muse Dash · 太鼓达人 · osu!**。其余全部是原版镁塔顿 EX 的弹幕交互。
- 音游段每个音符都有打击音效，全部在 `src/synth.js` 里现场合成。
- 黄心规则照原版：只能向上射；白色攻击从不碰心；蓝色只在心静止时穿过，橙色只在心移动时穿过。

## 三幕结构

| 幕 | 视频时间 | 声音 | 内容 |
| --- | --- | --- | --- |
| 一 · 开关 | 0 – 14 s | 静默，只有音效 | 方块形态镁塔顿转身找「镜子」→ 黄心按下开关 → OH YES → 两盏落地聚光灯与烟雾 |
| 二 · 收视率之战 | 14 – 148.6 s | Death by Glamour 全曲（83 小节） | 见下方分镜 |
| 三 · 谢幕 | 148.6 – 178.6 s | 静默，电话铃与观众来电 | 收视率封顶 12000，观众来电，转向黄心，白闪断电，留黑 1 秒 |

镁塔顿 EX 的身体照原版分三个阶段崩坏：完整 →（55）双臂脱落 →（72）双腿炸飞 → 只剩躯干打出最终绝招。

| 74–75 | 终章 · 螺旋 | 核心转出三条螺旋闪电流，75 加入反向螺旋，交织成格子；黄心在格子缝里走「8」字 |

| 81 | 12000 | 五个收束重音 = 五个转轮依次砸下 1 · 2 · 0 · 0 · 0，最后一枪射进核心 → 金色 12000、彩纸、掌声 |

**终章弹幕**（`src/tl_finale.js`）：先定黄心的路线，再按路线放子弹 —— 每颗闪电发射前沿整条轨迹算一遍它和黄心的最近距离，小于 18 px 的直接不发，18–28 px 的算擦弹。黑球方块反过来：黄心开枪的时刻，方块恰好停在枪口正上方，被射碎，永远碰不到黄心。

## 音乐分析

`tools/analyze_music.py`（librosa）把分析结果写入 `src/analysis.js`。

| 项目 | 结果 |
| --- | --- |
| 速度 | **148 BPM 全曲恒定**，16 分音符 = 0.10135 s，一拍 = 0.4054 s，一小节 = 1.6216 s |
| 首拍 | 0.006 s |
| 长度 | 134.59 s = 83 小节（最后一击在 81 小节第 4 拍，之后余音） |
| 调性 | E 小调；56–71 转 C♯ 小调，72 转回 |

| 小节 | 音乐 | 要点 |
| --- | --- | --- |
| 0–3 | 干声铜管切分重音 | 2 小节循环：`1 2 3 3a 4 4&` / `1& 3 3a 4` |
| 4–7 | 放克贝斯进入 | 低音 B–E–D–E / E–G–A–D |
| 8–11 | 合成器主旋律 + 铺底 | 11 推升进全乐队 |
| 12–23 | 主题 A | 2 小节乐句，军鼓 2、4 拍 |
| 24–39 | 第二主题 | 32–39 重复 24–31；39 末尾空拍 |
| 40–54 | 全曲最响 | 4 小节乐句 40 / 44 / 48 + 52–54；43、47、51 低音逐拍上行 |
| 55 | 骤停 | 3-3-2 重音：16 分位 0 · 3 · 6 · 8 · 11 |
| 56–70 | 迪斯科 | 底鼓每个八分；64–71 重复 56–63 |
| 71 | 鼓组抽空 | 8 个八分底鼓 |
| 72–79 | 终章 | 半速宽广旋律；偶数小节第 14 个 16 分、奇数小节第 2 个 16 分是大重音 |
| 80–82 | 收尾 | 80 滚奏；81 收束重音在 16 分位 4 · 6 · 8 · 10 · 12；之后余音 |

`src/analysis.js` 还提供逐 16 分的 `kick / snare / hat / tone` 强度、旋律音高 `lead`、逐拍低音 `bass`，供谱面、光束和运镜取用。

## 工具

播放器本身只需要浏览器。分析字体、校验和导出需要 Python 3（`requirements.txt`：librosa / numpy / scipy / Pillow）、Node、ffmpeg 和 Playwright。

```bash
python tools/analyze_music.py                        # music.mp3 -> src/analysis.js
python tools/make_font.py                            # 新增中文后重跑 -> src/glyphs.js（宋体，需 Windows）
python tools/fill_glyphs.py                          # 没有宋体时：用 GNU Unifont 补缺字
node tools/check.cjs                                 # 碰撞 / 完美线 / 第一人称 / 音效名 全片校验（240 Hz）
node tools/check.cjs --cut=tiktok                    # 同上，竖屏版
node tools/frames.cjs work/f 12.5 40.3 --bars        # 按小节渲染若干帧（不加 --bars 则为秒）
node tools/render.cjs [--cut=tiktok] [--gpu]         # 导出成片
python tools/sheet.py out.png 4 work/f/*.png         # 拼成联系表
node tools/eval.cjs "MV.TL.rating.at(MV.T.at(81,3)).v"
```
